# Sunflower · 英语陪同兼职

Sunflower 是一款微信小程序，帮助学生查找英语陪同兼职，也方便企业发布岗位或预约学生译员。

## 现有功能

| 学生端 | 企业端 |
| --- | --- |
| 按地点、收入、时段和技能筛选岗位 | 发布岗位，设置工时、计薪方式、交通补贴和招聘人数 |
| 申请、撤回及查看录用结果 | 查看申请，确认录用或标记未录用 |
| 设置空闲日期、技能、校区参考点和报价 | 按档期、预算、技能和距离查找可预约的学生 |

录用后会生成订单，记录约定薪资、工时、服务地点和其他约定。学生提交实际工时，企业确认后进入待付尾款。首次开通后，账号类型固定为学生或企业。

当前版本使用**本机演示数据**。登录、岗位和订单暂未跨设备同步，支付、退款和结算均为模拟流程。开发测试请使用虚拟资料。

## 本地运行

1. 克隆 [Sunflower 仓库](https://github.com/caozhisfather/sunflower)。
2. 用微信开发者工具导入**仓库根目录**。根目录的 `project.config.json` 已将小程序源码目录设置为 `sunflower/`。
3. 在导入界面选择测试号，或填写你有开发权限的小程序 AppID。点击「编译」打开模拟器。

在仓库根目录执行本地回归测试：

```powershell
node scripts/test-local-flow.js
```

测试使用独立内存数据，覆盖双角色流程和账号锁定。模拟器操作参见 [手动验收清单](TEST-CHECKLIST.md)。

## 云数据库准备

[CloudBase PostgreSQL 建表脚本](cloudbase/schema.sql) 可以粘贴到 CloudBase PostgreSQL **测试环境**的 SQL 编辑器，初始化 11 张业务表。字段和执行后检查方法见 [字段说明](cloudbase/FIELDS.md)。

建表后还需接入微信账号和云函数，才可以跨设备发布、申请和录用。进度及联调条件见 [架构与实施清单](ARCHITECTURE-CHECKLIST.md)。
